# MASAR PRO | أكاديمية مسار

منصة تعليمية عربية لتعلّم أساسيات الفوركس والذهب، والتحليل الفني، وإدارة المخاطر والانضباط. المحتوى تعليمي عام ولا يقدم توصيات تداول أو ضمانات أرباح.

## ما تتضمنه الأكاديمية
- منهج تعليمي منظم ووحدات ودروس.
- مكتبة استراتيجيات تعليمية.
- مختبر حالات سوقية تدريبية.
- مختبر تدريب عملي: قراءة الشموع قبل كشفها، استيراد OHLC، تثبيت قواعد استراتيجية، واختبار تاريخي محلي بعينة زمنية منفصلة.
- حاسبة حجم مركز تعليمية وتقييم مهارات بمصفوفة من 100 نقطة.
- سجل تحليلات محلي قابل للتصدير.
- محاكي تداول ورقي دون أموال حقيقية.
- أدوات حساب المخاطر والعائد إلى المخاطرة.
- سجل تداول وقائمة فحص قبل الصفقة.
- اختبارات ومراجعات وخطة تعلم.
- قاموس مصطلحات ورسوم توضيحية.
- تطبيق ويب قابل للتثبيت (PWA).

## حسابات MASAR PRO
- تسجيل الدخول عبر Supabase Auth.
- تفعيل الحسابات يدوياً بعد تأكيد الدفع من المسؤول.
- كلمة مرور مؤقتة ينشئها النظام، ويُطلب تغييرها عند أول دخول.
- الاشتراك مرتبط بتاريخ انتهاء، ويمكن للمسؤول تجديده أو إيقافه.
- محتوى المنهج يُقدّم عبر وظيفة خادمية تتحقق من هوية المستخدم وصلاحية اشتراكه قبل إرجاع المحتوى.
- لا توجد بوابة دفع آلية مفعلة في هذا الإصدار؛ الدفع والتحقق منه يدويان.

## النشر والبنية
- الواجهة: GitHub Pages عبر GitHub Actions.
- المصادقة والبيانات والوظائف الخلفية: Supabase.
- لا تضع مفاتيح الخدمة أو أسرار الدفع في ملفات المتصفح أو المستودع.
- ملف `assets/masar-config.js` مخصص لإعدادات المتصفح العامة فقط.
- اختبارات الجودة تعمل في GitHub Actions قبل النشر.

## ملاحظات تشغيلية
- لا تفعّل حساباً قبل التحقق من وصول الدفعة.
- أرسل كلمة المرور المؤقتة عبر قناة خاصة، ولا تضعها في رسائل عامة.
- راجع صلاحيات المسؤولين دورياً.
- فعّل حماية كلمات المرور المسرّبة في إعدادات Supabase Auth.
- راجع سجلات GitHub والنسخ المؤقتة القديمة؛ إعادة كتابة تاريخ الفرع لا تعني ضمان حذف كل نسخة أو cache خارج الفرع الحالي.

## إخلاء المسؤولية
المحتوى للتثقيف العام فقط وليس نصيحة استثمارية أو توصية بشراء أو بيع أي أصل. تداول الفوركس والذهب والمنتجات ذات الرافعة المالية ينطوي على مخاطر مرتفعة وقد يؤدي إلى خسارة رأس المال.
